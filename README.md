# 프레이피스 캐릭터 서고

TRPG 캐릭터 아카이브 사이트입니다. 주소: https://praypeace.github.io/Character_Archive/

## 구성
- `index.html` 사이트 (서가별 보기, 검색, 캐릭터 상세, 비밀번호로 여는 세션 로그)
- `characters.json` 캐릭터 목록. `img/<id>.webp` 캐릭터 그림
- `apps-script/서고_자동반영.gs` 원본 시트(◈프레이피스 캐릭터 모음집)에 붙이는 앱 스크립트
- `sync/` 앱 스크립트가 보내는 자료 (모음집 글자는 가려진 `dump.bin`, 새 탭 그림 `img/`)
- `tools/` 모음집 글자를 캐릭터 목록으로 바꾸는 파이썬 코드 (`sync.sh`)
- `.github/workflows/sync.yml` `sync/`가 바뀌면 자동 실행해 `characters.json`·`img/`를 고침

## 손으로 고치기
- `characters.json`에서 캐릭터의 `서가`·`룰`·`시스템`·`img`·`공개`는 자동 반영이 덮어쓰지 않습니다.
- `"고정": true`를 넣은 캐릭터는 자동 반영이 아예 건드리지 않습니다.
- `"공개"`를 `O`가 아닌 값으로 바꾸면 사이트에서 숨겨집니다.

## 비공개 자료
세션 로그(키퍼·플레이어)는 이 저장소에 두지 않습니다. 별도 구글 시트 '◈프레이피스 세션 로그 (비공개)'에 있고, 앱 스크립트 웹 앱이 비밀번호를 확인한 뒤에만 사이트에 보내 줍니다.
